## 5. 추가 검증 항목
- 다중 사용자 동시 접속
- 빠른 연속 명령 입력
- WebSocket 데이터와 화면 수치 일치 여부
- 중간 단계에서 미래 개표 결과 미노출 여부
- 서버 재연결 후 새 재생 정상 작동

## 6. 알려진 제한사항
- 실제 선거 API를 사용하지 않음
- 모든 데이터는 교육용 가상 데이터
- 현재는 단계별로 HTTP API를 재조회하여 화면 갱신
- 서버 재연결 시 이전 개표 상태 자동 복원 미지원
- 서버 오류 기록은 Chrome Console에 남을 수 있음
